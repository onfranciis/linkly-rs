# Security Policy

## Supported Versions

Linkly RS is pre-1.0 and under active development. Only the latest code on
`main` is supported with security fixes — there are no maintained release
branches yet.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately by emailing [hello@onfranciis.dev](mailto:hello@onfranciis.dev)
with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal example is ideal)
- Any relevant environment details

You should expect an initial response within a few days. Once a fix is
available, a coordinated disclosure and release will follow, and you'll be
credited for the report unless you prefer otherwise.
